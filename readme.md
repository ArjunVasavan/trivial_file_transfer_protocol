## Description

Creating a **simple implementation of the Trivial File Transfer Protocol (TFTP)** using **C**.

This project focuses on understanding:

* UDP socket programming
* Client–server communication
* Basic TFTP protocol flow

It does **not** aim to be a full RFC-compliant implementation — only the core concepts are implemented for learning purposes.

## Installation

Clone the repository:

```bash
git clone https://github.com/ArjunVasavan/trivial_file_transfer_protocol
cd trivial_file_transfer_protocol
```

## Compilation

```bash
make
make clean
```

## Usage

Run server:

```bash
./tftp_server
```

Run client:

```bash
./tftp_client
```

## Requirements

* GCC compiler
* Linux/Unix system
* Basic knowledge of networking
